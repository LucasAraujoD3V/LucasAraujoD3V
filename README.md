## `> ls -la ./projects`

<br>

**`🏍️ Site Viper — bikeestoque.com.br`**
B2B wholesale portal for a motorcycle/bike parts distributor. NestJS BFF + React/Vite
storefront in front of Magento (catalog) and Bling ERP (stock & invoicing).
Shipped: ASAAS/MercadoPago payment webhooks with PIX confirmation polling, automatic
NF-e issuance, real-time reserved-stock sync between warehouses, and a full technical
SEO recovery (indexing, sitemap, structured metadata).

**`📦 Kairos 2.0 — ERP sync & operations platform`**
Self-hosted successor to a no-code (Lovable) system: React/TypeScript frontend on
Supabase (self-hosted Postgres + PL/pgSQL), deployed via Docker + Nginx/Certbot on a
VPS. Built the ERP→cloud sync layer (Python services reading a legacy Firebird
database), materialized views that replaced client-side filtering at scale, container
import/customs cost tracking with price-trend dashboards, and an installable PWA for
factory-floor use.

**`🖥️ Home server & VPS infrastructure`**
Self-hosted Nextcloud/WebDAV, Portainer and Code Server on a home server, exposed
publicly through a Cloudflare Tunnel — no port-forwarding, no exposure to a dynamic
public IP. Remote Wake-on-LAN relay over a private mesh network, scoped deploy keys
per project, systemd-managed services.
